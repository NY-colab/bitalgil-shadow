# 호랑아, 도망쳐! — KBO 마스코트 추격전

기아 타이거즈의 호랑이와 삼성 라이온즈의 백사자가 달리는 비공식 팬메이드 브라우저 미니게임입니다.

- [게임 플레이](https://ny-colab.github.io/bitalgil-shadow/kbo-chase/)
- **방향키 왼쪽/오른쪽**: 좌우 이동, **위쪽/Space**: 점프, **아래쪽**: 슬라이딩, **P**: 일시정지
- 모바일에서는 화면 버튼 또는 스와이프 조작
- 8프레임 러닝 스프라이트, KBO 야구장, 장애물 및 황금 야구공
- 300m마다 경기장 테마 변경, 위험도에 따라 뒤쫓는 백사자가 가까워지는 연출
- PC·모바일, 서버 없이 정적 HTML/JS로 실행 가능

본 게임은 공식 구단 또는 KBO와 무관한 팬 제작물입니다.
